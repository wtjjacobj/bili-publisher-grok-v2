# 投稿文案中文人名本地化设计

## 目标

投稿助手生成的标题、简介和标签面向中文读者。人物名称应使用中文通行译名或规范中文音译，避免直接照搬英文人名，也避免在身份不确定时猜测人物。

## 命名规则

1. 有可靠中文通行译名时，统一使用通行译名。例如 `Elon Musk` 写作“埃隆·马斯克”，`Anakin Skywalker` 写作“阿纳金·天行者”。
2. 没有通行译名、但来源信息能确认原名和身份时，根据人物姓名所属语言生成规范中文音译；标题、简介和人物标签均使用中文名。
3. 无法确认人物身份或姓名时，不创造姓名，改用“视频中的男子”“现场主持人”“表演者”等画面可确认的称谓。
4. 公司、产品、赛事和行业缩写不按人名处理。`SpaceX`、`NBA`、`FIFA`、`OpenAI` 等可保留原文；已有稳定中文品牌名时可使用中文名。
5. 不因中文化而扩充未经来源证实的身份、国籍、职业或人物关系。

## 生成流程

文案提示词明确要求模型先判断文本中的拉丁字母名称属于人物还是品牌，再按上述规则生成标题候选、简介和标签。第一次生成结果仍由现有质量检查接收；若发现疑似未本地化的英文人名，则把具体问题作为复核反馈交给备用模型重新生成。

为避免把品牌误判成人名，自动检查只标记常见的英文人名形式，例如连续两个首字母大写的英文单词。品牌白名单和全大写缩写不触发该问题。最终语义判断仍由生成模型完成，不做机械字符串替换。

## 错误处理

- 无法确定通行译名时，优先规范音译，不能用未经证实的中文公众人物姓名代替。
- 无法确定原名对应的具体人物时，删除人名，使用中性称谓。
- 检查器只负责触发一次复核，不直接修改标题、简介或标签，防止破坏上下文。

## 验证

- 单元测试覆盖英文双词人名会触发复核、品牌及缩写不会触发复核、纯中文文案正常通过。
- 运行现有完整测试和服务构建，确保投稿、活动和截图功能不受影响。
- 使用受控元数据样例检查：英文人名输入得到中文人名输出，身份不确定的样例不凭空命名。

## 不在本次范围

- 不建立大型固定姓名数据库。
- 不为每次投稿增加联网搜索步骤。
- 不修改视频字幕中的英文原文，只调整投稿标题、简介和标签。
